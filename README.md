# Task 3: Linear Regression

## Objective
The objective of this task is to implement and understand Simple and Multiple Linear Regression using Python and Scikit-learn. The project focuses on predicting house prices based on relevant features and evaluating the performance of the regression model.

## Dataset
**House Price Prediction Dataset**

The dataset contains information about houses, including different features that can influence their prices. These features are used to train a machine learning model to predict house prices.

The dataset can be obtained from Kaggle or another relevant source.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- NumPy

## Concepts Covered
- Data loading and preprocessing
- Exploratory data analysis
- Train-test splitting
- Simple Linear Regression
- Multiple Linear Regression
- Model training and prediction
- Regression evaluation metrics
- Regression visualization
- Model coefficient interpretation

## Implementation Steps
1. Import the necessary Python libraries.
2. Load the House Price Prediction dataset using Pandas.
3. Perform data preprocessing and handle missing values.
4. Select relevant features and the target variable.
5. Split the dataset into training and testing sets.
6. Train a Linear Regression model using Scikit-learn.
7. Predict house prices using the trained model.
8. Evaluate the model using MAE, MSE, and R² Score.
9. Visualize the actual and predicted house prices.
10. Interpret the regression coefficients to understand feature relationships.

## Evaluation Metrics

### Mean Absolute Error (MAE)
Measures the average absolute difference between actual and predicted values.

### Mean Squared Error (MSE)
Measures the average squared difference between actual and predicted values.

### R² Score
Indicates how well the model explains the variation in the target variable.

## Visualizations
The project includes visualizations to understand the relationship between house features and prices, along with comparisons between actual and predicted house prices.
